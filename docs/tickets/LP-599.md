# LP-599 — The composer put "correctly" back after the spec removed it

## What shipped to a processor

LP-597 rewrote DT-8's satisfied template deliberately:

> ~~"this mortgage is marked as paid off at closing, so its payment is **correctly** excluded from the
> **back-end debt-to-income ratio**"~~
> "the application marks this mortgage as paid off at closing, so it is excluded from the debt ratio"

Both removals were the point. *"Correctly"* claimed the check had confirmed the lien **belongs**
excluded — that it sits on the subject property — which nothing established. *"Back-end
debt-to-income ratio"* asserted a property of a calculation that is gated on any file missing taxes
and insurance.

The next staging run produced this:

> "The existing mortgage with UNITED WHSLE MORT is **correctly excluded** from the debt-to-income
> ratio."

The composer dropped "back-end" and put "correctly" straight back. **Fixing a template does not hold
when a model rewrites it** — which is the whole point of a composition pass, and the reason the guard
has to live in the composer rather than in the spec.

## The fix, and the line it must not cross

A prompt rule plus a deterministic check on six adverbs: `correctly`, `properly`, `appropriately`,
`accurately`, `rightly`, `as it should be`. Each describes whether something was done **right** — a
judgment about the engine's own work — and none is ever needed to state a fact about a loan file.

**`verified`, `documented` and `confirmed` are deliberately NOT in that list.** The same prompt's
worked examples for a passing finding are *"Employment is verified for the full two-year history"* and
*"Reserves are fully documented"*. Those describe the file's evidence, not whether someone got
something right. Banning them would have broken guidance written three rules above in the same file,
so the prompt rule states the carve-out explicitly and a test pins it.

The rejection is retryable (LP-597's mechanism), because the fallback for a rejection is the raw
template — and DT-8's raw template is exactly the engine-prose reading this was meant to fix.
