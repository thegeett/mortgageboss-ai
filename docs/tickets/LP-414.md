## A3 — should LF-6T3N gain an HOA statement / homeowners binder? **No (leave-clean).**

Adding an HOA statement would give LF-6T3N a non-zero HOA line where it has `$0` today, changing the DB DTI card /
reserves view; adding a binder changes the insurance line. **Argument: leave-clean.** LF-6T3N is the realism
anchor — it need not carry every document, and a genuinely-absent HOA/binder is honest (`housing.hoa_monthly` /
`housing.insurance_monthly` correctly abstain). The real-figure materialization those documents would prove
belongs in a **scenario fixture** (Part B `build_subject_housing_snapshot`), which carries them without touching a
live calculation. Recommendation followed: **no documents added to LF-6T3N; only the field-name renames + the one
MISMO fact.** (No live surface changes as a result.)
