# LP-706 — match the model's snippet against the text we already have, properly

- **Ticket:** LP-706 (LP-700 series, 1 of 4)
- **Status:** Open
- **Scope:** Backend — `services/field_boxes.py`
- **Prompts changed:** none. **Extra AI calls:** none. **New dependencies:** none.

## The idea in one line

We already know where every word on a text page is. Stop requiring the model to retype
those words *exactly* before we will look for them.

## How it works today

`field_boxes.py` calls `page.search_for(snippet)` — a literal, exact search. If the model
wrote `Gross Total 15,000.00` and the page's text layer holds `Gross  Total  15,000.00`
(two spaces), or the figure sits in a table cell split across two text spans, or the page
uses a ligature, the search returns nothing and the field gets no box.

## What changes

Match against `page.get_text("words")` — the word list with a rectangle per word — instead
of searching for a literal string. Normalise both sides before comparing (collapse
whitespace, fold ligatures, strip currency symbols and thousands separators), then take the
**union rectangle of the matched words** as the box.

Fall back down a chain rather than giving up, which is what production grounding systems do:
the verbatim snippet → the normalised snippet → the extracted **value** itself. Always try
to ground rather than return nothing.

When the same text appears more than once on the page, prefer the occurrence on the cited
page and nearest the cited position, and where it is still ambiguous, return **no box**
rather than a guess — see LP-709.

## Behaviour by document kind

| | what happens |
|---|---|
| **Text PDF** (78 docs) | The whole benefit lands here. Recovers most of the 11.8% of fields whose snippet is absent from the text layer only because of formatting. |
| **Scanned PDF** (17 docs) | **Nothing changes.** There are no words to match against. Needs LP-708. |
| **Mixed PDF** (6 docs) | Works on the pages that have text; the scanned pages are unaffected. The matching is per page, so this falls out naturally. |
| **Image** (0 today) | Nothing changes — an image has no text layer. Needs LP-708. |

## Acceptance

- [ ] Measured before and after on the stored corpus: the "snippet absent from the text
      layer" bucket shrinks, and the "found on the cited page" figure is reported as a number,
      not an impression
- [ ] A page with the same value twice returns no box rather than the first one
- [ ] No box moves that was previously correct — the existing matches are a regression baseline
