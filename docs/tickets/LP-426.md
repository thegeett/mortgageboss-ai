## ⚠️ The synthetic-fixture caveat (Priya weighs this before signing)

The measurement is on **LP-418 SCENARIO documents**, not real VOEs / offer letters, and each document's
`document_type` is **hand-set and always correct** (`voe` / `employment_offer_letter`). So the AI's task reduces
to "read the given type + corroborating fields," and the 100% measures **income_docs' report GIVEN a correctly
classified document** — it does **not** measure (a) genuine recognition of a real VOE from messy content, nor
(b) a mis-classification (a doc the upstream classifier typed wrong). The LP-393 synthetic-data caveat applies:
these are constructed inputs. A real-file run (or classifier-error cases) would harden this further.
