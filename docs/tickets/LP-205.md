# LP-205 — MISMO section assembler

## Summary

The first Stage-1 snapshot assembler: reads the already-parsed, persisted
1003/MISMO data (`LoanFile` terms, `Property`, `Borrower` + stated
income/employers, file-level stated liabilities/assets) and reshapes it into
LP-204's flat `mismo` section — a `dict[str, Field | PiiField]` keyed by a stable
dotted convention. It does **not** parse MISMO and touches no other section.

Architectural decisions recorded in **ADR-242** (`decisions.md`).

## Acceptance criteria

- [x] Flat `dict[str, Field|PiiField]` matching LP-204's `mismo` type.
- [x] Stable dotted-key scheme; indices from a stable ordering (position / id),
      not list position — same input → identical keys.
- [x] Each value → `Field.present(..., source=parsed)`; **confidence null**
      everywhere (never fabricated).
- [x] SSN → `PiiField.from_raw` (masked display + match-hash, raw never stored),
      salted by loan_file_id.
- [x] Absent ≠ empty: a value MISMO didn't carry → key omitted; a genuine empty
      string → present-empty; the two are distinguishable.
- [x] Pure read + reshape; graceful on missing sub-data (no error).
- [x] Unit tests (in-memory fixtures) + real-file check (LF-6T3N, PII masked).
- [x] ADR added (ADR-242) and referenced here.
- [x] CI green: ruff, mypy, snapshot test suite.

## Phase 0 findings

- **Reuse exactly:** LP-204 `mismo` = `dict[str, Field|PiiField]` (`SnapshotField`);
  LP-203 `Field.present`, `PiiField.from_raw`. LP-204 hardened `Field.value` to
  reject `Decimal`/`date` → the assembler stringifies.
- **Persisted MISMO models & columns:** LoanFile (program/purpose/refinance_type/
  loan_amount/note_amount/note_rate_percent/amortization_type/amortization_months);
  Property (address_line/2, city, state, postal_code, property_type, occupancy_type,
  estimated_value, purchase_price, valuation_amount, attachment_type,
  construction_method, financed_unit_count); Borrower (first/middle/last_name, ssn,
  date_of_birth, marital_status, is_primary, dependent_count, citizenship,
  declarations) + StatedIncomeItem (monthly_amount, income_type, employment_income)
  + StatedEmployer (employer_name, is_current); StatedLiability (liability_type,
  monthly_payment, unpaid_balance, holder_name); StatedAsset (asset_type, value,
  holder_name).
- **PII = borrower SSN only.** No account-number column on Stated assets/liabilities
  this branch.
- **Parsed-but-dropped (gaps, not surfaced):** borrower `current_address_*`,
  property `county` (store-everything, only on `phase3_5_1`), raw MISMO catch-all;
  and no `transaction.*` (transactions live in bank-statement extractions).
- **LF-6T3N** present with 2 borrowers / 3 income / 7 liabilities / 5 assets /
  property.

## What was built

`app/verification/snapshot/mismo_section.py`:
- `build_mismo_section(*, loan_file, borrowers, property_, liabilities, assets)` —
  pure reshape → flat map.
- `load_mismo_section(db, loan_file)` — async loader (`only_active` queries) →
  `build_mismo_section`.
- `_scalar` (JSON-scalar coercion, Decimal→str, date→ISO, StrEnum→value), `_slug`
  (declaration keys), `_active` (soft-delete filter).

Exports added to `__init__.py`. Real-file smoke:
`app/scripts/mismo_section_smoke.py` (`uv run python -m app.scripts.mismo_section_smoke LF-6T3N`).
Tests: `tests/verification/snapshot/test_mismo_section.py` (9 cases).

**Real-file result (LF-6T3N):** 122 keys, both borrower SSNs masked
(`***-**-3207`, `***-**-0373`) with `v1:` match-hashes, all `source=parsed`,
`confidence=None`; the known silently-empty asset row surfaces as an absent
`asset.3` (no keys) — honest absent≠empty.

## Assumptions & decisions

- **Key convention + stable ordering (ADR-242):** dotted keys, 1-based indices;
  borrowers by `borrower_position` (tie-break id), nested/file-level collections by
  ascending row `id`. Deterministic, not semantic — index gaps (all-null row) are
  legitimate and stable.
- **`NULL` → absent → omit the key.** A non-null value is present, including `""`
  (present-empty), so "not carried" (key absent) ≠ "carried blank" (present-empty).
  Never emits a present-null placeholder; never fabricates.
- **`source=parsed`, `confidence=null`** on every field — deterministic parse, no
  fabricated confidence.
- **PII = SSN only**, via `PiiField.from_raw`. Contact PII (email/phone) not
  surfaced; DOB surfaced (identity).
- **Values stringified** for JSON scalars (LP-204 `Field.value` guard).

## Post-review hardening (code review, 2026-07-10)

Fixes applied (see the [ADR-242](../../decisions.md) amendment):

- **[correctness] Uniform soft-delete filtering.** The pure/public
  `build_mismo_section` filtered income/employers via `_active()` but iterated
  borrowers/liabilities/assets raw, trusting the caller's SQL — a leak of
  soft-deleted rows (incl. a deleted borrower's SSN) if built from unfiltered data.
  It now `_active()`-filters every child collection; `_active` uses the shared
  `SoftDeleteMixin.is_deleted`.
- **[correctness] Present-empty SSN.** `if borrower.ssn:` dropped a blank SSN as
  absent; the SSN now routes through `put(..., pii=PiiKind.SSN)`, whose absent test
  is `value is None`, so a blank stays present-but-empty (masked placeholder).
- **[security] PII declared per key.** PII routing moved from the hardcoded
  `if borrower.ssn` branch into `put(key, value, pii=…)`, so a future account-number
  column is one `pii=` argument away and can't leak as a plaintext `Field`.
- **[correctness] `_scalar` fails loud.** It now raises on an unhandled type instead
  of `str()`-fabricating a repr (which defeated `Field.value`'s guard).
- **[correctness] Malformed `declarations` degrade gracefully.** A non-dict JSON
  value is skipped, not `.items()`-crashed.
- **[honesty] Cross-run key stability corrected** to "deterministic within a run"
  (positional indices shift on a sibling soft-delete/insert) in the docstring + ADR.
- **[cleanup] Loader dedup** (`_by_loan_file` helper) and a documented
  company-scoped-`loan_file` precondition on `load_mismo_section`.

Deferred: `_slug` declaration-name collisions (two names → one key, last-write-wins);
extracting the cross-module `_slug` / money-stringify duplicates into shared helpers.
