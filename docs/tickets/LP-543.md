# LP-543 — FR-5 (recurring undisclosed debit): measured, not built

**Decision: do not build FR-5 now.** Measured 2026-08-18 against the staging corpus before
committing to LP-519 Phase 2. Recorded so the question is not re-litigated from memory.

## The state FR-5 was in

- a row in `rule_kinds.csv` — *"Recurring undisclosed debit, Fraud, judgmental, ai_judgment"*
- **no spec file**, not in `ACTIVE_RULE_IDS`
- its three tags (`txn.counterparty`, `txn.is_recurring`, `txn.implies_obligation`) declared in
  `fact_tags.csv` but **produced by nothing** — absent from `tag_production.yaml`
- blocked for the reason `activation_bars.yaml:2194` records: *"FR-5's declared 'pattern across
  statements' is unanswerable from a context that shows one transaction."*

Nothing reads money-out at all. All three active transaction rules scope identically:

```
AS-1   scope: txn.is_money_in eq in
AS-2   scope: txn.is_money_in eq in
AS-12  scope: txn.is_money_in eq in
```

**FR-5 would have found zero undisclosed obligations.** Every recurring debit large enough to be a
loan payment is on the 1003 already, and the single real discrepancy is caught by a rule that exists.

## What this does and does not establish

**Every row reads `files = 1`.** All bank-statement transactions in staging come from one loan file.
This is a complete census of what we hold, and what we hold is one borrower.

So this does **not** establish that FR-5 is worthless. It establishes that this corpus cannot justify
building it, and that LP-519 Phase 2's per-transaction model cost would currently buy nothing
measurable. That is a corpus problem, not an engineering one.

## Revisit when

More than one loan file carries bank statements. At that point re-run the query above before deciding
— the answer may invert, and the numbers here are specific to one borrower's spending.

FR-5's open threshold question is unresolved and still needs a domain call whenever it is built:
a recurring $40 debit is a streaming subscription, a recurring $450 debit is a car payment, and unlike
the deposit floor there is no agency text to derive the line from.
