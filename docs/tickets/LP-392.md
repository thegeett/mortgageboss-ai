# LP-392 — Generate Priya's labeling worksheet from the REAL loan file

## What this ticket is

The committed judgment worksheet is generated from the DE-IDENTIFIED fixture (Jordan A Rivera / Taylor M
Nguyen / First Springfield Bank), but Priya validates against the REAL documents (Akash / Bansari Patel /
BofA). The `context` column showed fixture values while `source_document` pointed at the real PDFs — so she
opened a real PDF, saw the real name, and the row said "Jordan A Rivera": she could not cross-check, and
`stmt.owner_matches_borrower` ("does this account holder match the borrower?") was **unanswerable** by
construction. This produces a LOCAL, real-data worksheet she can actually use — every value from the DB, never
guessed — kept **gitignored** (real PII, never committed). The committed fixture worksheet is untouched (CI).

- The committed fixture worksheet is byte-unchanged; no tag/rule/producer change; `ACTIVE_RULE_IDS` unchanged
  (20); full suite green.
