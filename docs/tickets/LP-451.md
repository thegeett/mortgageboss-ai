**READ-ONLY. No file changed but this report. No model calls** (Geet had ~$0.95 of API credit; everything below
is read from `rule_kinds.csv`, the classification doc, `tag_production.yaml`, `_RECIPES`, `_LIST_SPECS`, the 109

## What this ticket is

37 rules are live of **120 in scope** (135 total − 15 out-of-scope). **83 remain unwritten.** Nobody knew which
are now writable against a field surface that grew from 18 extractors to **109** (+232 typed fields in LP-446,
+52 → now 60 lists in LP-443). This applies **all five gates to every one** — the discipline five prior censuses
skipped (they asked only "are the inputs produced?" and over-counted 4–10×).

## Method + authoritative sources

- **`rule_kinds.csv` (rationale column) + `docs/stage2-rule-classification.md`** — the rule's own description,
  **quoted, never inferred from the name** (the OC-1 trap). AUTHORITATIVE for what each rule checks.
- **`tag_production.yaml` + `vocabulary_extra.yaml`** — the tags that EXIST (produced). AUTHORITATIVE.
- **`derived.py` `_RECIPES`** (28 recipes), **`documents_section.py` `_LIST_SPECS`** (60 lists), the **109
  extraction models** (field surface), **`activation_bars.py`** (candidate status). AUTHORITATIVE.
- **`rule_tags.csv` is LINEAGE, not direct-read** (LP-424): it names a rule's raw INPUT tags, which differ from
  what a live spec reads wherever a derived producer sits between. A difference is NOT drift — I used it only to
  seed "what data does this rule need," then checked the field/list/recipe surface directly.
- **PLANNING artifacts (not authoritative for "writable"):** the catalog's kind/threshold columns describe
  intent; the five gates decide reality.

## The five gates (applied in order; a rule can fail several — all are reported)

0 vacuity · 0b redundancy · 1 inputs available (a catch-all-only field is NOT available — it is discarded) ·
2 expressible (date-vs-date native; date-vs-today / ordered-pairwise / set-coverage need a derived producer;
fuzzy cross-document matching needs an AI reasoner) · 3 calibrated · 4 threshold.
