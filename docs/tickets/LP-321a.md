# LP-321a — Fix the LF-6T3N regression fixture/test to reflect live DTI gating

**Status:** Complete. **Branch:** `phase3_new_AI_arch_finding_stage2`.
**ADR:** [ADR-262](../../decisions.md). **Depends on / cross-ref:** LP-317 (the PII stripping that
introduced the fiction), LP-318 (calculator gating), LP-321 (the orchestrator + its test), the

## What it is

The gating investigation found that the orchestrator's `test_lf6t3n_full_run_zero_fired` was **green
on a fiction**: it ran on a frozen fixture whose `calc.dti` had been stripped during LP-317's PII
reduction (`gated=False`, `breakdown=[]`), so AS-1 evaluated normally and asserted "0 fired" — but
the **live** pipeline on real LF-6T3N GATES the DTI (no insurance binder → `housing.insurance_monthly`
unknown → `auto_amount` None → LP-318 gated calc) → AS-1 **couldnt_checks**. A green test on behavior
that doesn't match reality is worse than no test; this corrects the fixture + test to the live
outcome, and adds a guard so the fiction can't silently return.

**The live gating is correct; the fixture was wrong** — not the reverse.

## Assumptions & decisions

- **The FIXTURE was wrong, the live gating is right.** LF-6T3N genuinely has no insurance binder, so
  the DTI genuinely cannot be trusted — gating it (and couldnt_checking AS-1) is the correct
  fail-closed behavior. The test now asserts that, not a fabricated "everything satisfied."
- **couldnt_check ≠ satisfied.** The corrected test explicitly asserts the AS-1 subjects are NOT
  satisfied and NOT fired — the deposits are unevaluated-for-threshold (the DTI is gated), not
  cleared. Asserting only "0 fired" (as before) hid this.
- **Sourcing coverage preserved.** The Stage-A/B sourcing (verified / self_asserted strengths) is
  independent of the DTI gate, so it is asserted separately — that real-trace coverage is not lost
  when the DTI gates.
- **No-PII approach.** The gating signal is presence/None, which carries no PII. The only live PII in
  the DTI was the line **labels** (borrower + creditor names) and DB-UUID **keys** — both
  genericized. Amounts (no identity) match the fixture's existing LP-317 posture (amounts kept, names
  stripped).
- **Guard.** `dti.gated is True` + `back_end_dti is None` are now hard assertions, so a silent
  re-strip fails loudly.
