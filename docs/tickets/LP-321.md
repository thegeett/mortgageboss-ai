# LP-321 — Orchestrator + partial-snapshot semantics

**Status:** Complete. **Branch:** `phase3_new_AI_arch_finding_stage2`.
**ADR:** [ADR-261](../../decisions.md). **Depends on:** LP-312 (raw snapshot), LP-313/314 (Stage
A/B), LP-315 (gate + rules), LP-316 (findings), LP-318 (calculators), LP-319 (judgment rules), §3A/§3D.

## What it is

The single entry point that runs a FULL verification on a loan file, in dependency order —
`raw snapshot → Stage A → Stage B → (calculators) → (contradiction audit) → rules → findings` — with
**partial-snapshot semantics** (a stage failure degrades gracefully, never fails the whole run) and
**caching** (unchanged inputs reuse frozen tags). It is **assembly** of the pieces already built; it
owns ORDER, DEGRADATION, and CACHING only — no new tag/rule/calculator/finding logic.

## Acceptance criteria

- [x] `run_verification` runs the full pipeline end-to-end (keyless), producing persisted findings:
  the unsourced large deposit FIRED (open), the verified one satisfied — the AS-1 result end to end.
- [x] Dependency order: Stage B runs after A (its `has_identified_source`/`source_strength` tags
  exist only because A's `is_money_in` did); rules + findings after tags.
- [x] Partial-snapshot: a Stage-B **per-call** failure → those tags unknown-with-reason → the
  affected AS-1 rules `couldnt_check` **with reason**; a rule NOT depending on them (OC-2) STILL
  evaluates; the run COMPLETES. A **wholesale** Stage-B exception → the orchestrator backstop
  degrades the stage (pre-B snapshot kept), records it, run completes.
- [x] Cache: a re-run with unchanged inputs reuses tags (0 re-production); a re-run with ONE changed
  document re-produces only that entity (one batch), reuses the rest.
- [x] Degradation visibility: `VerificationRun.degradations` records what degraded + why (absent
  sections, unknown-with-reason production markers, backstopped exceptions).
- [x] Real-data: the frozen LF-6T3N trace threaded through the orchestrator → **0 fired**.
- [x] Reproducibility metadata (model + vocab version) recorded; frozen snapshot persisted. ruff +
  mypy(`app/`) clean; full suite green.

## Assumptions & decisions

- **Dependency order** = raw (calculators inside it) → A → B → rules → findings. The DAG is honored
  by A-before-B; the producers handle intra-stage ordering.
- **Partial-snapshot = the system-level fail-closed.** The producers already fail-close per call
  (bad AI response → unknown-with-reason tags); the orchestrator adds a BACKSTOP for a wholesale
  stage exception (catch, keep the pre-stage snapshot, record a degradation). It **lets every rule
  run and gate** — a rule with degraded inputs `couldnt_check`s (LP-315), a rule without them runs
  normally; the orchestrator never skips a rule silently. The run always completes.
- **Degradation visibility, not hidden.** The result carries `degradations`: absent-with-reason raw
  sections, unknown-with-reason production markers scanned from the tags (matched by
  failed/truncated/malformed), and any backstopped stage exception.
- **Cache-by-content-fingerprint.** `TagCaches` (Stage-A + Stage-B) is threaded across runs; the
  producers key on the raw-fact fingerprint, so unchanged inputs are cache hits and only a changed
  document's entity re-produces. The cache is loan-file-agnostic (keyed on facts).
- **Assemble, don't reimplement.** No new logic. Two slots are inert today, and the ADR says so:
  the **calculators** run inside `build_snapshot` (their inputs are stated financials, not Stage-A/B
  tags, so no separate post-tag step is needed), and the **contradiction audit** has no deterministic
  cross-checks wired yet (the gate takes a `contradiction` flag; the orchestrator passes False — the
  audit is a future ticket).
- **OC-2 honesty.** The occupancy structural tags OC-2 reads are not produced by any stage yet
  (OC-1/ID-4), so OC-2 `couldnt_check`s on a snapshot lacking them — honest fail-closed, and it still
  demonstrates "a rule that doesn't depend on the failed Stage-B tags still runs."
- **`base_snapshot` / `produce_tags` seams** let a test (and reproducibility) run the rules over an
  already-tagged frozen snapshot (LF-6T3N) without re-deriving tags.

## Deferred to LP-322
