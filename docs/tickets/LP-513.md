# LP-513 — No `per_borrower` rule produces a finding on a real file

**Status:** open (not started) · **Severity:** HIGH — nine live rules silently produce nothing
**Found by:** LP-511's investigation

## The defect

On LF-WCHG — a real file with 30+ documents and a parsed MISMO borrower — **not one `per_borrower` rule
produced a single finding.** Absent from the results entirely:

`IN-1, IN-12, IN-13, IN-14, IN-15, IN-16, ID-5, CR-4, CR-10`

All nine are in `ACTIVE_RULE_IDS`. All nine contributed nothing. There is no error, no `couldnt_check`,
no log line — the enumerator returns an empty subject list and the rules simply do not appear.

## Why

`_per_borrower` resolves subjects through documents' `belongs_to` attribution (LP-202/385), which is the
evidence-based upload link — deliberately never a name match. If no document is attributed to a borrower,
the file has no borrower subjects, and every per-borrower rule evaluates zero times.

The attribution requires `borrower.{n}.borrower_id` in the MISMO facts to link to a document's
`belongs_to` UUID. Which half is failing on this file is the first thing to establish.

## Why it matters

These are not marginal rules. They include the borrower's stated-vs-documented income shortfall (IN-1 —
the rule PIN #1 was written for), ID expiry (ID-5), undisclosed tradelines (CR-4) and collections
(CR-10). A file can pass with all nine silently inert, and the output gives no indication that a third of
the live rule set never ran.

**This is also what made LP-509-A3 a regression:** moving IN-3 to `per_borrower` moved it into this
broken class, which is why LP-511 reverted the enumeration.

## First diagnostic steps

1. Does the file's MISMO carry `borrower.{n}.borrower_id`? (The parser emits it; confirm it survives.)
2. Do any documents have a non-empty `belongs_to`? Attribution is set at upload/extraction time.
3. Is this specific to MISMO-imported files, to files whose documents pre-date the borrower row, or
   universal? Check a second file before concluding.

## Acceptance criteria

- [ ] Root cause identified with evidence, not inference
- [ ] A per-borrower rule produces findings on a real file
- [ ] **A guard that fails when an ACTIVE rule contributes zero evaluations across a whole run** —
      silence is the actual defect here, and it should not be able to recur unnoticed
- [ ] Decide whether IN-3 returns to `per_borrower` once this is fixed (LP-511)
