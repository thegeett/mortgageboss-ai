# LP-961 — The import review shows what she must act on, not how the sheet was read

- **Ticket:** LP-961 · Phase 4.5 Stage 3 follow-ups (the owner, 2026-10-04)
- **Source:** the owner's questions on the review screen after re-uploading LF-DH8V's sheet. Points 4, 5,
  6, 9 and 10: "I think we do not need to inform that"; "We show 2 warning but not actual warning? I am not
  sure what value it add"; "What values it add?"; "I do not think we should display this info"; "not sure
  what value it adds?"

## What was removed from the review screen (`round-review.tsx`, `review-rows.tsx`)

- **"Read by rules (uwm v1) — no AI"** and the AI form ("Split by AI (split v1) · rules found no rows").
  `readerLine` is deleted. The reader stays in `parse_report` for debugging.
- **"N warnings · N lines left over · N duplicates."** It showed a count of warnings without the warnings
  themselves, plus the reader's own bookkeeping.
- **The reader's warnings in "Check before importing"**, such as "unrecognised loan-information line at
  line 435". The number was `int(line.y)`, a position on the page, not a line number. These warnings are
  about the loan-information box, never about a condition. They are still stored in `parse_report.warnings`.
- **The owner chip and its source on each review row**: "Owner not known · from code map", "Title · from
  'TC:' prefix". The plan made after import says who acts on each item.

## What stays

- **"Check before importing" appears only when she must look**: a line that fits no condition, which could
  be a lost condition (now with "This line from the sheet did not fit into any condition. If one is a
  condition, add it."), or rows the AI split, which keep their "I checked the flagged rows" gate.
- The format chip, Date printed, Full list / Just some, Round date, the condition and heading counts, the
  underwriter-notes count, and the wrong-file warning.

## Not changed (noted for the owner)

- The **drawer and the list** still show the effective owner (the Owner select, the owner filter). Those
  are her choices after import, not the reader's guess. Only the review screen's guess and its source went.
- `owner_hint` and `owner_hint_source` are still written on import. Retiring them belongs with LP-962's
  decision on the code maps.

## Tests

`round-review.test.tsx`: the four tests that asserted the removed text are replaced by four that assert it
is gone, each with a positive control in the same render:
- no reader line (the format still shows);
- no counts or warning text, and no box for a warning alone (the summary line still renders);
- a left-over line is still shown with its sentence;
- no owner guess or source on a row (the row's Edit control still renders);
- an AI-split round names no reader.

Mutations, restored from a copy: showing the box for a warning alone, dropping the left-over sentence, and
an "Owner not known" back on the row all fail a test. The first try at the box mutation matched two
anchors and did not run; it was redone with a unique anchor.
