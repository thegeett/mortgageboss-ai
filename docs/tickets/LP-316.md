# LP-316 — Finding output: verdict outcome states + provenance + subject_key

**Status:** Complete. **Branch:** `phase3_new_AI_arch_finding_stage2`.
**ADR:** [ADR-256](../../decisions.md). **Depends on:** LP-315 (the evaluation result),

## What it is

Persists LP-315's AS-1 evaluation results (as refined by LP-314a) as durable findings — by
**EXTENDING the existing `Finding` model, not forking it**. Adds a new evaluation-outcome axis,
a stable per-deposit `subject_key` column, the load-bearing-tag provenance inline, and an
append-only per-finding event log. **Single-run** — cross-run reconciliation is LP-322.

## Five outcome states (not four)

The earlier plan said four; **LP-314a added a `needs_review` verdict** (self-asserted large
transfer), so this persists **five** — using LP-314a/LP-315's real verdict names:

| Verdict (LP-315/314a) | evaluation_outcome | severity |
|---|---|---|
| `fired` | `open` | red |
| `satisfied` | `satisfied` | green |
| `needs_review` | `needs_review` | yellow |
| `couldnt_check` | `couldnt_check` — **now persists** (left no record before) | yellow |
| `not_applicable` | *not persisted* | — |
| — | `no_longer_applies` (retirement) | defined; produced by **LP-322**, not single-run |

## Assumptions & decisions

- **Orthogonal outcome axis.** `evaluation_outcome` records the check result; it does not collide
  with severity or resolution. Severity is a coarse color derived from the outcome; the outcome is
  the precise signal.
- **`subject_key` = content_id** (LP-312), never re-extracted amount/date (they drift). Partial
  unique index (live, subject-keyed rows only) so soft-deleted / legacy findings don't participate.
  `details.subject_key` retained for the `finding_identity` substrate.
- **Provenance inline** with `source_facts` (an extension to LP-315's `LoadBearingTag`);
  empty-reasoning findings are refused (§3D: a verdict must say WHY). Origin `deterministic_rule`.
- **`couldnt_check` persists** — a first-class "we couldn't check this, here's why" record.
- **Coexistence, not replacement.** Direct-INSERT persistence; `reconcile_findings` untouched;
  the partial-unique index tolerates its soft-delete.
