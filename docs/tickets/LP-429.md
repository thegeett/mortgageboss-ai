## THE FOUR-ITEM PHASE-0 REPORT (what her sign-off covers)

**① The height — 0.95.** LP-397's proposal. The routing driver `owner_matches_borrower` measures **1.0 (11/11**
after LP-402/403 added the six negative cases; was 5/5, one-sided, at proposal). The bar's recorded numbers
(threshold 0.95, measured_accuracy 1.0) are confirmed consistent.

**② `ships: auto` — and the fact that changed.** LP-397 proposed `auto` but recommended **ratify-only "until a
negative case is tested."** That condition is **now MET**: LP-398 built six negative statements and LP-404 shows
**four firing correctly (N1/N3/N4/N6)**. So ratify-only's original justification is satisfied and **AS-6 ships
AUTO** (the bar's current value). Structural kind → `auto` is legal; the LP-424 kind cross-check passes.

**③ What the bar measures — the multi-tag question (ADR-338).** AS-6 reads three tags scored differently:

| tag | vs Priya's labels | role |
|---|---|---|
| `owner_matches_borrower` | **11/11** | ROUTING — fired vs satisfied |
| `non_borrower_co_holder` | **11/11** | ROUTING — the joint-account needs_review row |
| `holder_name_variance` | **5/11** (LP-403) | REASON string on a needs_review row (not routing) |

**Resolution:** the bar measures the **VERDICT-DRIVING (routing) tags** — `owner_matches_borrower` +
`non_borrower_co_holder`, both 11/11 → `measured_accuracy = 1.0 ≥ 0.95`. `holder_name_variance` (5/11) drives
only the reason wording on a `needs_review` row — which a human reviews — so it is **not verdict-load-bearing and
does not gate the bar**. Taking the weakest of ALL read tags (0.45) would wrongly block a rule whose VERDICT is
11/11. AS-6 is the first multi-tag rule → this sets the precedent → **ADR-338**. The bar's `load_bearing_ai_tags`
is set to the two routing tags; `holder_name_variance` is deliberately excluded, recorded in the bar. **This did
NOT block activation** (routing = 1.0), so no STOP was required.

**④ The variance residual (LP-403).** She labeled **N2 (Roberta) = `nickname`, P2 (Bob) = `other`**; the AI says
the **reverse**, and the conventional reading favours the AI (Bob is Robert's classic nickname; Roberta is a
distinct given name — **her labels may be swapped**). This affects the variance SCORE + some reason wording, NOT
the routing. Recorded as a known refinement AS-6 ships with (a Priya taxonomy round, its own ticket).

## ADR

**ADR-338** — a multi-tag rule's activation bar measures its VERDICT-DRIVING (routing) tags, not every tag it
reads; a reason-only tag (here `holder_name_variance`, 5/11, on a human-reviewed `needs_review` row) does not gate
the bar. AS-6 is the first multi-tag rule, so this sets the precedent (it refines LP-390-5a's weakest-tag rule
rather than contradicting it).
