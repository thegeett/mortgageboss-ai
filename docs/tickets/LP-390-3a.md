# LP-390-3a — Regenerate Priya's worksheet from the DB (real identities) + fix has_identified_source

## What this ticket is

The LP-390-3 judgment worksheet was generated from the DE-IDENTIFIED fixture (Jordan Rivera / First Springfield
Bank) while its `source_document` column points at the REAL PDFs (Akash Patel / BofA). A name-match row like
`stmt.owner_matches_borrower` ("does this account holder match the borrower?") is unanswerable — and even one
visible mismatch erodes trust in the whole sheet. This ticket generates Priya's working copy from the REAL DB
(real names, PII-contained, uncommitted), fixes the `has_identified_source` context, drops the non-labelable
orphan tags, and — the governing rule — preserves every label she has already entered.

## What Phase 0 found (the gate of record reshaped the ticket)

Priya had **already been labeling** an active de-identified copy (`…judgment1.csv`, 78 goldens vs the prior 52,
+ 35 notes). The LP-390-3 SOURCE-TRACE reframing **worked**: she labeled **all 16 `has_identified_source`**
rows she had previously skipped, plus `stmt.owner_matches_borrower` (8) and `income.has_2yr_history` (2). Per
the decision on this ticket, that copy is **adopted as the committed golden** (it is de-identified — no PII),
and the real-name DB copy is generated separately for her to cross-check the name rows.

- **`write_db_worksheets` produces real names, verified.** It builds from the REAL DB loan `LF-6T3N`
  (`build_snapshot` + the governed `document_filenames_by_content_id`) and reuses the SAME `build_worksheet`
  generator, so it inherits this ticket's context fix. Spot-check (into gitignored `calibration-local/`):
  `stmt.owner_matches_borrower` context reads `account_holder_name=AKASH V PATEL BANSARI N PATEL; …` with

- **PII containment, verified.** `guard_pii_safe_out_dir` REFUSES an in-repo committable path (raises on
  `docs/calibration`) and allows only outside-the-repo or the gitignored `calibration-local/`. `git status`
  shows nothing under `calibration-local/` — the real-PII worksheet can never be committed.
