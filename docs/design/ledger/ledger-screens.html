Status — three channels, always

Color, glyph shape and word all carry the state. Drop the color and the row still reads — which is what happens for the 1 in 12 men with a color vision deficiency, and on a printed file.

Provenance — how we know, which is not a status

Located — page and spot Page known, spot not located Inferred, not read Not on this document
The extraction pipeline stores a page and a verbatim snippet, never a rectangle — the box is derived by searching the page's text layer, so it is absent rather than approximate when the search fails, which on a scanned document is every field. A missing box is therefore a normal condition and is never drawn as a fault: the value, the page and the quoted line are all still there. Provenance is a separate channel from status — a field can be perfectly verified and still have no box.
